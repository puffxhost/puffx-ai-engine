# Security notes

Use HTTPS at a reverse proxy for public deployments. Generate unique high-entropy API/admin passwords and protect the environment file. API keys created through the admin endpoint are returned once and stored as SHA-256 digests; revoke by key ID. Restrict dashboard access to trusted administrators. Current admin authentication uses a bearer password, so use a long unique secret and TLS. Public API routes use `RATE_LIMIT`; admin routes use the tighter `ADMIN_RATE_LIMIT` setting by default. Both limits are process-local and IP-based, not distributed or per-key quotas. When deploying behind Nginx, the provided config forwards the client IP. Configure Uvicorn to trust only the actual proxy address; otherwise clients may share one proxy IP rate-limit bucket. Uvicorn defaults to trusting 127.0.0.1, so a Dockerized proxy may need a different trusted address. Do not expose Ollama port 11434 publicly. Browser and mobile apps must not embed server secrets.
