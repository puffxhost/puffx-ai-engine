# Security notes

Use HTTPS at a reverse proxy for public deployments. Generate unique high-entropy API/admin passwords and protect the environment file. API keys created through the admin endpoint are returned once and stored as SHA-256 digests; revoke by key ID. Restrict dashboard access to trusted administrators. Current admin authentication uses a bearer password, so use a long unique secret and TLS. Public API routes use `RATE_LIMIT`; admin routes use the tighter `ADMIN_RATE_LIMIT` setting by default. Both limits are process-local and IP-based, not distributed or per-key quotas. When deploying behind Nginx, use the provided forwarded-client-IP configuration so different users do not share the proxy's rate-limit bucket. Do not expose Ollama port 11434 publicly. Browser and mobile apps must not embed server secrets.
